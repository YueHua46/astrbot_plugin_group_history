# astrbot_plugin_group_history · 《群史》编纂委员会

> 用国家档案馆的严肃，记载群友的抽象。

AstrBot 插件：一个常驻群里的「编纂委员会」。它每晚通读前一天的群聊实录，找出值得载入史册的名场面，用维基百科的口吻写成正式词条，并在群里「官宣」。词条带编号、修订史、真实引文、分类体系；群友可以检索、抽阅、申报事件、调阅彼此的人物档案，最终还能把全部词条装订成一本书。

## 它能干什么

```
📜 群史编纂委员会 · 编纂公告
现将新事件载入《群史》。

【凯子龙虾事件】（群史字第 0013 号）

凯子龙虾事件，发生于 2026 年 9 月 14 日凌晨，系本群成员凯子就
"龙虾是否属于海鲜"发表长篇暴论、并遭全体成员围剿之事件。史称
"龙虾之夜"。……

—— 执笔：编纂委员会
```

- **每日自动编纂**：凌晨（默认 2 点）侦察前一天实录 → 编委会评审（无大事则歇笔）→ 首席执笔官撰写词条 → 群里官宣
- **词条修订史**：事件有后续就修订原词条而不是另开新条，维基式版本历史可查
- **真实引文**：词条引用的原话全部来自真实聊天记录（含时间与发言人），点得上号
- **分类体系**：暴言 / 深夜 / 饮食争议…… 词条之间自然形成「参见」网络
- **人物档案**：`/群史 @某人` 自动为其撰写一份严肃的百科式人物条目
- **群友申报**：`/快记 刚才的大事`，委员会立即调阅近几小时实录立卷
- **出版**：`/群史出版` 把所有词条装订成一本带封面、目录、分类索引的《群史·第一卷》HTML（可打印成 PDF）

## 指令

| 指令 | 说明 |
|---|---|
| `/群史` | 随机抽阅一条群史（按史评等级加权） |
| `/群史 关键词` / `/群史 编号` | 检索 / 调阅 |
| `/群史 @某人` | 调阅其人物档案 |
| `/群史列表` | 总目 |
| `/群史分类 [分类名]` | 分类表 / 分类词条 |
| `/群史修订 编号` | 查看词条修订史 |
| `/快记 事件描述` | 群友申报重大事件入史 |
| `/群史出版` | 装订《群史·第一卷》 |
| `/群史帮助` | 使用说明 |
| `/删史 编号 确认` | （管理员）抹除某段历史 |
| `/群史模型` | 查看/切换执笔模型 |
| `/群史试跑 [天数]` | （管理员）试编某日卷宗并当场宣读 |
| `/群史自检` | 委员会健康检查 |

## 安装

在 AstrBot Web 面板「插件市场 → 从仓库安装」中填入本仓库地址，或把本目录放进 `data/plugins/` 后重启 AstrBot。

无任何外部依赖（requirements 为空），历史消息直接读取 AstrBot 主数据库。

## 配置

装好后面板里可调（全部有中文说明）：

| 配置 | 默认 | 说明 |
|---|---|---|
| `provider_id` | gemini-3.8-flash-high | 执笔模型，下拉选择；留空用默认模型 |
| `run_hour` | 2 | 编纂时刻（夜间静默干活） |
| `announce_hour` | 12 | 官宣时刻：词条到点才发群里，避免深夜打扰；-1 = 编完立即发 |
| `run_interval_days` | 1 | 编纂周期：每 N 天跑一次，调大降低刷屏 |
| `max_announces_per_day` | 2 | 每次编纂的官宣条数上限，0 = 只入库不播报 |
| `max_entries_per_day` | 2 | 每日入史上限（防通货膨胀） |
| `significance_threshold` | 6 | 入史门槛（1-10），调高只记大事 |
| `backfill_days` | 14 | 首次启动静默回溯天数 |
| `probation_days` | 14 | 试运行期（官宣带【草稿】标记） |
| `allowed_groups` | 空 | 只编纂指定群 |
| `style_prompt` | 空 | 文体补充要求，想换口味写这里 |

## 工作原理

```
每日凌晨
  └─ 拉取前一日 platform_message_history（按群分组）
      └─ 压缩成「HH:MM 昵称：内容」实录（超长自动抽稀/分片）
          └─ 侦察员（LLM）：提取候选事件 + 真实引文
              └─ 评审（LLM）：合并去重、按 significance 定选
                  └─ 执笔官（LLM）：撰写维基体词条
                      ├─ 撞题？→ 走修订流程并入旧词条
                      └─ 新词条入库（词条/修订/引文/人物关联）
                          └─ 群里官宣
```

数据全部存放在 `data/plugin_data/astrbot_plugin_group_history/history.db`（独立 SQLite），不碰 AstrBot 主数据库。

## 隐私说明

- 词条与引文全部保存在你自己服务器的本地数据库，不上传任何第三方
- 词条只在群里播报群里本来就看得到的内容
- 每条历史都可被管理员 `/删史`（软删除，留档可查）
- 试运行期内所有官宣带【草稿】标记，方便磨合文风

## 致谢与趣味

「编委会」「侦察员」「首席执笔官」皆为同一个大模型的数个分身。它们日复一日地阅读、评审、落笔，把转瞬即逝的聊天记录，锻造成一部只属于你们的正史。
